Kiến trúc tối giản, hiệu năng bare-metal

Mọi thành phần được biên dịch tĩnh thành một tệp thực thi duy nhất, loại bỏ hoàn toàn gánh nặng bảo trì container hay runtime.

Tự động dò quét cổng TCP & Docker

Đọc trực tiếp socket lắng nghe trên hệ thống và danh sách Docker container, tự phân tích tiêu đề HTTP để gợi ý tên và đường dẫn chính xác.

Cách ly bảo mật Funnel

Khi mở dịch vụ ra Internet công cộng bằng Funnel, TailRouter tự động chặn toàn bộ truy cập vào trang quản trị và REST API từ bên ngoài.

Tailscale-Funnel → /bambu 200 OK
Tailscale-Funnel → /router 403 Forbidden
Tailscale-Funnel → /api/* 403 Forbidden

Tự khởi động & Gỡ bỏ sạch sẽ

Tích hợp sẵn trình đăng ký systemd, OpenRC, launchd và Windows Registry. Hỗ trợ gỡ cài đặt hoàn toàn chỉ với một lệnh hoặc một cú nhấp chuột.

$ tailrouter service install Enabled
$ tailrouter uninstall -y Clean Wipe
